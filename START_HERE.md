# Start here

> Generated by [start-here](https://github.com/minoruthenextkami-afk/start-here) · 2026-09-23

## What this is
Agent Skill + tiny CLI that writes a one-screen `START_HERE.md` onboarding brief for any repository. Works in Claude Code, Codex, OpenCode, Cursor via the Agent Skills standard.

## Run it

| | Command |
|--|--|
| Install | `npm ci` (none — zero deps; Node ≥18) |
| Dev | edit `skills/start-here/SKILL.md` |
| Test | `npm test` (prints version) |
| Build | n/a — plain ESM, no bundle |

Stack: Node.js (ESM) · no runtime deps · Agent Skills `SKILL.md`

## Where to change what

| I want to… | Open |
|------------|------|
| Change skill behavior / prompts | `skills/start-here/SKILL.md` |
| Change install targets or CLI | `bin/start-here.mjs` |
| Change package metadata / bin name | `package.json` |
| Update marketing copy | `README.md` |
| Update example output | `examples/START_HERE.example.md` |
| Add harness path (e.g. new CLI) | `bin/start-here.mjs` → `TARGETS` / `GLOBAL` |
| Test install | `node bin/start-here.mjs init && node bin/start-here.mjs check` |

## First PR (suggested)
Replace the README GIF placeholder with a real 3–5s terminal capture, or add a `skills-ref validate` step in CI (`npx skills-ref validate ./skills/start-here`) so frontmatter regressions fail PRs.

## Gotchas
- Skill must be **copied** to each harness path — they do not read `skills/` root by default
- `name` in frontmatter must equal directory name `start-here`
- Zero-dependency: do not add npm deps without a strong reason (keeps `npx` instant)

## Layout
- `skills/start-here/` — canonical `SKILL.md` source
- `.claude/ .opencode/ .codex/ .agents/ .cursor/` — vendored copies for multi-CLI
- `bin/start-here.mjs` — `init` / `check` / `version`
- `examples/` — sample `START_HERE.md` output
